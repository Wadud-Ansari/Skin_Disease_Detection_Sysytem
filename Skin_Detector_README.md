# Skin Disease Detector

A deep learning system that classifies dermoscopic skin lesion images into 7 disease categories using transfer learning on EfficientNet-B3, with Grad-CAM explainability and a deployable Streamlit web app.

## Features

- **Transfer learning classifier** built on EfficientNet-B3 (ImageNet pretrained), fine-tuned on the HAM10000 skin lesion dataset
- **Two-phase training**: classifier head warm-up, then full-network fine-tuning with cosine learning rate scheduling
- **Class-weighted loss** to handle the natural class imbalance in dermatology datasets
- **Grad-CAM explainability** — visual heatmaps showing which regions of an image influenced each prediction
- **Streamlit web app** — upload an image and get a prediction, confidence scores, and a Grad-CAM overlay in the browser
- **ngrok tunneling** to make the app accessible via a public URL directly from Colab

## Disease Classes

| Code | Name | Typical Risk |
|---|---|---|
| MEL | Melanoma | High |
| NV | Melanocytic Nevi | Low |
| BCC | Basal Cell Carcinoma | Moderate |
| AKIEC | Actinic Keratosis | Moderate |
| BKL | Benign Keratosis | Low |
| DF | Dermatofibroma | Low |
| VASC | Vascular Lesion | Low-Moderate |

## Model Architecture

- Base: **EfficientNet-B3** (`torchvision.models.efficientnet_b3`, ImageNet1K weights)
- Custom classifier head: Dropout → Linear(→256) → ReLU → Dropout → Linear(→7)
- Phase 1: train only the classifier head (base frozen), 5 epochs, Adam @ 1e-3
- Phase 2: unfreeze entire network, fine-tune, 10 epochs, Adam @ 1e-4 with cosine annealing LR

## Dataset

Trained on the **HAM10000** ("Human Against Machine with 10000 training images") skin lesion dataset, which pairs a metadata CSV of one-hot disease labels with lesion images. Place it as `skin.zip` in your Google Drive before running the notebook, or update the `zip_path` in cell 1 to point at your own copy.

## Setup

### Training (Google Colab recommended — needs a GPU)

1. Upload your dataset as `skin.zip` to Google Drive
2. Open the notebook in Colab (Runtime → Change runtime type → GPU)
3. Run cells top to bottom through the evaluation and Grad-CAM sections
4. The best model checkpoint saves to your Google Drive as `skin_disease_best_model.pth`

### Running the Streamlit app

The notebook writes `app.py` and can launch it directly from Colab via `ngrok` for a shareable public URL, or you can run it locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Make sure `skin_disease_best_model.pth` is in the same directory as `app.py`.

If running from Colab with `ngrok`, you'll be prompted to paste your own **ngrok auth token** (get a free one at [dashboard.ngrok.com](https://dashboard.ngrok.com)) — never hardcode this token in the notebook, especially before pushing to a public repo.

## Usage

1. Run the notebook to train (or use the pre-trained `.pth` checkpoint)
2. Review the classification report and confusion matrix on the held-out test set
3. Use `gradcam_single()` or `gradcam_grid()` to visualize model attention on sample images
4. Use `predict_with_confidence()` to see the full probability distribution for any image
5. Launch `app.py` to try predictions interactively through a browser

## Known Limitations

- HAM10000 has a strong class imbalance (melanocytic nevi dominate); class weighting helps but doesn't fully eliminate bias toward common classes
- This is a research/educational demo, **not a diagnostic medical device** — predictions should never be used to make real medical decisions without a licensed professional
- Grad-CAM highlights correlation, not causation — a "hot" region doesn't guarantee the model is reasoning about it the way a dermatologist would
